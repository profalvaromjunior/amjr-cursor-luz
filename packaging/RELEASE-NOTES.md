**AMJR Cursor Luz + AMJR Cursor Menino** — gratuito e para fins educacionais (Windows 10 e 11).

- Cursor Luz: luz em volta do ponteiro e onda a cada clique. `Ctrl + Alt + L` liga/desliga.
- Cursor Menino: o ponteiro vira o menino apontando (animado ou parado). `Ctrl + Alt + M` liga/desliga.

Baixe o `AMJR-Cursor-Luz.zip`, extraia fora de Imagens/Documentos (ex.: `C:\AMJR`) e abra os `.exe`. Se o Windows avisar: **Mais informações › Executar assim mesmo**.

Pacote compilado pelo GitHub Actions a partir do código deste repositório. Vídeo do passo a passo: https://prof.alvaromjunior.com/cursor-luz
